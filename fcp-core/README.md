# ВНИМАНИЕ: это НЕ исходники настоящего FCP-Core

Модуль воссоздан по использованию в `fcp-jobs` **только для сборки и проверки**
(compile/`provided`-зависимости): настоящий `fcp-core` живёт в закрытом
FCP-репозитории и на игровом сервере стоит как плагин `FCP-Core`.

- Не устанавливайте эти jar-файлы на сервер.
- Не расширяйте эти файлы новой логикой; новые вызовы добавляйте только так,
  чтобы они были совместимы с реальным `FCP-Core`.
- Все публичные FQN, сигнатуры и контракты выписаны из байткода и исходников
  `fcp-jobs-1.0.0.jar`, поэтому API совпадает, но поведение реализаций —
  упрощённое (например, `color()` поддерживает `&` и `&#RRGGBB`).
