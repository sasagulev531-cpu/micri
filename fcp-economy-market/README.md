# ВНИМАНИЕ: это НЕ исходники настоящего FCP-EconomyMarket

Модуль воссоздан по использованию в `fcp-jobs` **только для сборки и проверки**
(`provided`-зависимость с координатами `Frontiks:fcp-economy-market:1.0.0`).
На сервере работает настоящий плагин `FCP-EconomyMarket`.

- Не устанавливайте этот jar на сервер.
- Интерфейс `EconomyService` выписан из байткода fcp-jobs-1.0.0.jar и ТЗ
  (`addCoins(UUID, int)` и т.д.).
